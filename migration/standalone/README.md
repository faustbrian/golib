# Standalone Repository Migration

This directory defines the deterministic split of the public modules formerly
stored below `pkg/`. The canonical implementation source is commit
`2ce9d76b35d5f69f216307758fc49c01a5ada315`, proven by successful CI run
`32743496559`.

`repositories.json` is generated by:

```sh
go run ./cmd/golib standalone-manifest \
  --source-commit 2ce9d76b35d5f69f216307758fc49c01a5ada315 \
  --ci-run 32743496559
```

It accounts for 82 destination repositories, 140 retained modules, and 110
releasable modules. `secret-store` is intentionally excluded.

## Immutable Version Collisions

The public Go proxy and checksum database already contain incompatible
`v1.0.0` versions for `github.com/faustbrian/go-postgres` and
`github.com/faustbrian/go-outbox`. Those versions cannot be overwritten.
The canonical packages use these collision resolutions:

- `github.com/faustbrian/go-postgres` starts its canonical line at `v1.0.1`;
  the legacy `go-postgresql` repository is archived.
- `github.com/faustbrian/go-transactional-outbox` starts at `v1.0.0`.

## Legacy Audit

Before any remote branch, tag, release, or repository name is changed, run:

```sh
./scripts/capture-standalone-repository-audit.sh
```

The command writes `/Users/brian/Developer/golib/.migration-audit.json`. That
private file records existing repository metadata, refs, releases, and public
module versions. It is deliberately outside this repository because it is an
operational rollback and accountability artifact rather than public package
documentation.

The audit must be recaptured only when remote state intentionally changes. It
must not be rewritten after destructive migration operations to obscure the
pre-migration state.

## Standalone Population And Dependency Resolution

Populate the extracted repositories with their standalone module identities,
repository tooling, and governance files:

```sh
go run ./cmd/golib standalone-populate \
  --destination-root /Users/brian/Developer/golib
```

Owned stable module checksums cannot be generated from a proxy containing
unfinished dependency trees. Settle all module files in the manifest's release
waves instead:

```sh
./scripts/tidy-standalone-modules.sh
```

The script removes stale owned checksums, uses task-owned disposable Go caches,
builds only completed dependency waves into a deterministic local proxy, runs
`go mod tidy` with `GOWORK=off`, and finishes with `go mod tidy -diff` for all
140 retained modules. Missing owned dependency artifacts fail before Go can
fall back to a legacy public version.

For a read-only consumer rehearsal after repository contents are final, create
an empty output directory and build the complete local proxy:

```sh
go run ./cmd/golib standalone-proxy \
  --destination-root /Users/brian/Developer/golib \
  --output /path/to/empty/proxy
```
