
## Method

Each row reports benchstat's median of ten independent Go benchmark samples and
its 95% confidence range as a percentage. No outliers were discarded. The
samples ran on a developer workstation with other repository work present, so
small differences inside the reported uncertainty are not treated as
meaningful. Every comparison uses the same process, command, capacity, weights,
and parallelism, but the semantic differences documented in
[`../performance.md`](../performance.md) remain material.
